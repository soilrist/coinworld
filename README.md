# 담이농장 홈페이지

담이농장 유기농 고구마 소개용 정적 사이트입니다. 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 보입니다. 예전 HTML 연습 파일은 `practice/` 폴더로 옮겨 두었습니다.

## 공개하기 (카페24 웹호스팅)

`master`에 저장되면 GitHub Actions(`.github/workflows/deploy.yml`)가 홈페이지 파일을 카페24에 FTP로 올립니다. 처음 한 번만 저장소 **Settings → Secrets and variables → Actions → New repository secret**에서 아래 값을 넣어 주세요. 비밀번호는 이곳에만 넣고 채팅이나 파일에는 적지 않습니다.

- `CAFE24_FTP_HOST`: FTP 주소 `damefarm1.cafe24.com` (다르면 카페24 호스팅 관리 화면의 FTP 정보에서 확인)
- `CAFE24_FTP_USER`: FTP 아이디
- `CAFE24_FTP_PASS`: FTP 비밀번호
- `CAFE24_FTP_DIR`: (선택) 올릴 폴더, 비워 두면 `/www`

올라가는 파일: `index.html`, `styles.css`, `site.js`, `favicon.svg`, `robots.txt`, `sitemap.xml`, `data/`, `admin/`, `photos/` 안의 사진

주소는 https://담이농장.com 기준입니다. 카페24에 SSL(https)이 없으면 카페24 호스팅 관리 → 보안서버(SSL)에서 무료 인증서를 켜 주세요.

## 관리자 화면 (가격·품절·공지·사진 고치기)

홈페이지 주소 뒤에 `/admin/`을 붙여 들어갑니다. 예: https://담이농장.com/admin/ (휴대폰에서도 됩니다)

관리자 화면에서 고칠 수 있는 것:

- **상품 · 가격 · 품절**: 상품 이름, 설명, 무게별 가격, 품절 스위치, 주문하기 버튼 주소
- **공지사항**: 제목, 날짜, 내용, 맨 위 고정. 공지가 하나도 없으면 홈페이지에 공지 칸이 나오지 않습니다.
- **연락처 · 사업자 정보 · 사진**: 전화번호, 주소, 계좌, 인증 번호, 농장 사진

**저장**을 누르면 GitHub 저장소의 `data/` 파일(사진은 `photos/`)에 바로 기록되고, 1~2분 뒤 자동 배포로 카페24 사이트에 반영됩니다. 실수했으면 GitHub에서 그 파일의 History로 이전 버전을 볼 수 있습니다.

### 처음 한 번: 관리자 열쇠(토큰) 만들기

관리자 화면에는 아이디·비밀번호가 따로 없고, 저장소 주인 GitHub 계정에서 만든 **열쇠(토큰)**로 들어갑니다. 홈페이지 서버에는 로그인 정보가 저장되지 않아 예전처럼 서버를 뚫고 들어올 곳이 생기지 않습니다.

1. GitHub에 로그인한 뒤 https://github.com/settings/personal-access-tokens/new 를 엽니다.
2. Token name: `담이농장 관리자`, Expiration: 1년(366 days) 정도로 고릅니다.
3. Repository access: **Only select repositories** → `soilrist/damefarm` 하나만 고릅니다.
4. Permissions → Repository permissions → **Contents: Read and write** 하나만 켭니다. (Metadata: Read-only는 자동으로 켜집니다)
5. **Generate token**을 누르고 나온 `github_pat_…` 글자를 복사합니다. 이 글자는 비밀번호와 같으니 채팅이나 문자로 보내지 마세요.
6. `/admin/`을 열고 **액세스 토큰으로 로그인**을 누른 뒤 붙여넣으면 끝입니다. 같은 브라우저에서는 다음부터 바로 들어가집니다.

휴대폰에서도 쓰려면 컴퓨터 관리자 화면 오른쪽 위 계정 메뉴의 **모바일로 로그인** QR 코드를 휴대폰으로 찍으면 됩니다. "GitHub(으)로 로그인" 버튼은 별도 인증 서버가 있어야 해서 쓰지 않습니다.

토큰을 잃어버렸거나 남이 봤을 수 있으면 https://github.com/settings/personal-access-tokens 에서 그 토큰을 **Delete**하고 새로 만드세요. 지운 즉시 그 토큰으로는 들어올 수 없습니다. 다른 사람에게 맡길 때는 저장소 **Settings → Collaborators**로 그 사람 GitHub 계정을 추가하고, 그 사람이 자기 토큰을 만들게 하세요.

### 직접 파일로 고치기 (관리자 화면을 못 쓸 때)

GitHub에서 `data/products.json`(상품·가격), `data/notices.json`(공지), `data/farm.json`(연락처·사업자 정보·사진)을 열고 연필(✏️ Edit) 버튼으로 고친 뒤 **Commit changes**를 누릅니다. 따옴표(`"`)와 쉼표 모양은 그대로 두고 글자만 바꾸세요. 품절은 `"soldOut": true`, 판매 중은 `"soldOut": false`입니다.

## 사진 넣는 법

관리자 화면 **연락처 · 사업자 정보 · 사진 → 농장 사진 → 사진 추가**에서 사진을 고르고 설명을 적은 뒤 저장합니다. 큰 휴대폰 사진은 올릴 때 자동으로 작게 줄여집니다. 사진 파일 이름은 영어와 숫자로 지어 주세요 (예: harvest1.jpg).

사진이 하나도 없으면 사진 칸은 나오지 않고, 파일이 없는 사진은 자동으로 빠집니다.

## 고객 문의 게시판 (다음 단계, 아직 만들지 않음)

고객이 글을 쓰는 게시판은 글을 받아 저장할 서버가 필요해서 이번에는 넣지 않았습니다. 지금은 전화와 농라 주문서로 문의를 받습니다. 나중에 만든다면:

- 카페24 PHP + MySQL로 직접 만들기: 가능하지만 로그인 페이지, 글쓰기 폼, 파일 업로드가 다시 해킹 통로가 됩니다. 예전 해킹도 호스팅 파일이 뚫린 경우라 가장 위험합니다. 만든다면 파일 업로드 없음, 관리자 로그인은 IP 제한과 2단계 인증, 스팸 방지(캡차), 정기 업데이트가 필수입니다.
- 외부 서비스 쓰기(권장): 카카오톡 채널 1:1 채팅이나 네이버 톡톡 버튼을 링크로만 다는 방법은 우리 서버에 아무것도 저장하지 않아 안전합니다.
- 공개 Q&A가 꼭 필요하면 GitHub Discussions 같은 외부 게시판을 링크하는 방법도 있습니다.

## 보안

이 홈페이지는 서버 프로그램, 로그인 서버, 데이터베이스가 없는 정적 사이트라 예전 호스팅처럼 서버를 뚫고 들어올 곳이 없습니다. 홈페이지에는 외부 스크립트를 쓰지 않고, 보안 정책(CSP)을 넣어 이 저장소 안의 파일만 실행되게 막아 두었습니다.

관리자 화면(`/admin/`)은 편집기 프로그램(Sveltia CMS)을 버전과 무결성 해시를 고정해 불러오므로, 누가 그 파일을 바꿔치기하면 실행되지 않습니다. 관리자 화면은 GitHub에만 연결되고, 저장 권한은 토큰을 가진 사람만 있습니다. 검색엔진에는 관리자 화면이 나오지 않게 막아 두었습니다. 지켜야 할 것은 GitHub 계정과 토큰입니다.

- GitHub 계정에 2단계 인증(2FA)을 켜 두기
- 저장소 협업자(Settings → Collaborators)는 꼭 필요한 사람만
- 관리자 토큰은 이 저장소 하나, Contents 권한 하나로만 만들고, 공용 컴퓨터에서는 관리자 화면을 쓰지 않기 (썼다면 오른쪽 위 메뉴에서 로그아웃)
- 다른 사이트의 스크립트나 위젯 코드를 붙여넣지 않기
- 나중에 담이농장.com을 연결할 때는 도메인 등록 업체 계정 비밀번호를 바꾸고 2단계 인증을 켠 뒤, DNS가 GitHub Pages만 가리키는지 확인하기
