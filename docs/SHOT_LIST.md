# 촬영 필요 목록 (SHOT LIST)

이 문서는 실제 서비스 오픈 전 담이농장에서 촬영/확보해야 하는 이미지 목록이다.
현재 사이트는 실사 이미지가 없는 상태에서 "빈 박스"나 "IMAGE placeholder" 텍스트 대신,
브랜드 컬러 시스템 기반의 직접 디자인한 대체 비주얼(SVG 아트: 등고선 그래픽, 라벨 일러스트,
보태니컬 라인아트 등 — `src/components/art/`)로 채워져 있다. 아래 실사 촬영본이 확보되면
해당 컴포넌트를 실제 이미지(`next/image`)로 교체한다.

## 우선순위 1 — 브랜드 신뢰에 직접 영향

1. **대표 강여상 인물 사진** (정면 인물 사진, 밭 배경 인물 사진 각 1장 이상)
   → 대체 중: `FounderPortraitArt` (추상 타이포그래픽 플레이스홀더, 실제 인물 사진처럼 가장하지 않음)
   → 사용처: 홈 브랜드스토리 섹션, /story 페이지
2. **유기농산물 인증서 실물 스캔본** (인증번호 15100525)
3. **저탄소 인증서 실물 스캔본** (인증번호 2018-111)
4. **올가 마이스터 선정 관련 자료** (증서/기념패가 있는 경우)
5. **수상 상장 실물 사진** (전국 으뜸 농산물 한마당 품평회 — 실물 확보 후 게시, 미확보 시 노출 보류)
   → 대체 중: 텍스트 기반 카드
   → 사용처: /certification

## 우선순위 2 — 상품/구매 전환

6. **상품 실물 사진** — 3kg/5kg/10kg 박스, 호박고구마, 꼬마고구마 각각
   → 대체 중: `ProductLabelArt` (크래프트지 라벨 스타일 일러스트)
   → 사용처: 상품 카드, 상품 상세 갤러리
7. **택배 박스 포장 사진** (박스 상단뷰, 완충재 포함)
8. **선물용 패키지 사진** (있는 경우)
9. **군고구마/찐고구마 조리 이미지** (식탁 연출 포함)

## 우선순위 3 — 농장 다큐멘터리 톤

10. 무안 황토밭 광각 사진 (드론 항공샷 있으면 최상)
11. 고구마밭 잎/줄기 클로즈업
12. 수확 장면 (사람이 직접 캐는 모습)
13. 갓 캔 고구마 클로즈업 (황토 묻은 상태)
14. 세척/선별 작업 장면
15. 포장 작업 장면
16. 농장 전경 (건물/비닐하우스 등)

## 우선순위 4 — 방송/미디어

17. 방송 출연 관련 사진 (자체 촬영분에 한함 — 방송사 화면 캡처는 저작권상 무단 게시 금지)
18. 방송사 공식 다시보기 링크 확보 (KBS 6시 내고향, 채널A 무작정 커머스)
    → 확보 시 /broadcast 페이지에 "다시보기" 외부 링크 CTA 추가

## 촬영 가이드 (제안)

- 톤: 프리미엄 식품 다큐멘터리 (오설록/올가홀푸드 화보 참고)
- 색감: 워밍톤, 채도 과하지 않게, 황토/올리브/버건디 팔레트와 어울리는 보정
- 인물: 자연광, 정직한 표정, 과도한 연출 지양
- 상품: 그림자 있는 자연광 or 스튜디오 소프트박스, 크래프트지/리넨 배경 추천
- 포맷: 원본 고해상도(최소 3000px 장변) + 웹용 WebP/AVIF 변환은 개발 단계에서 처리
